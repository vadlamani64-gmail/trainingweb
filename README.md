# Nexora Tech Academy Website

A premium React/Vite landing page for a software training institute.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Main files

- `src/App.jsx` — page content and sections
- `src/styles.css` — complete visual design and responsive styling
- `index.html` — metadata and fonts

## Customize

Replace:
- `Nexora Tech Academy` with your institute name
- `training@example.com` with your real email
- Course wording as needed
- Any stats/testimonials only with facts you can substantiate
